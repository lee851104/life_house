## 三、資料格式

- 編碼：**UTF-8 with BOM**；分隔符號：逗號；**51 個欄位，34 個檔案的欄位完全一致**。
- 主要欄位：發生年度、發生月份、發生日期(yyyymmdd)、發生時間(hhmmss)、事故類別名稱、
  處理單位名稱警局層、發生地點、天候名稱、光線名稱、道路類別、速限、道路型態、事故位置、
  路面狀況、道路障礙、號誌、車道劃分設施、事故類型及型態、肇因研判、死亡受傷人數、
  當事者順位、當事者車種／性別／年齡、保護裝備、行動電話使用、當事者行動狀態、
  車輛撞擊部位、肇事逃逸類別、**經度、緯度**。
- `死亡受傷人數` 格式為 `死亡1;受傷0`（字串，需自行拆解）。
- ⚠️ **每個 CSV 檔尾都有 2 列非資料的註記列**：`資料提供日期：…` 與 `事故類別：…`。
  讀取時請濾掉（例如判斷第 1 欄是否為 4 位數年份），否則會混進統計。
  `A1_2024-2026_合併.csv` 與 `合併A2.py` 都已處理掉這 2 列。

## 五、常用操作

合併 A2 分月檔為年度單檔（檔案很大，約 500 MB／年，視需要才執行）：

```bash
python 合併A2.py 2024
```

以 pandas 讀取單月 A2：

```python
import pandas as pd
df = pd.read_csv("data/A2/A2_2024_01.csv", encoding="utf-8-sig", dtype=str)
df = df[df["發生年度"].str.fullmatch(r"\d{4}", na=False)]   # 濾掉檔尾註記列
accidents = df[df["當事者順位"] == "1"]                     # 每件事故一列
```

## 六、只要單一縣市時

```bash
python 篩選縣市.py 桃園市
```

**務必用 `發生地點` 的開頭縣市來篩，不要用 `處理單位名稱警局層`。**
國道與機場的事故由國道公路警察局／航空警察局處理，用單位篩會漏掉：

| 桃園（2024–2026） | 依發生地點 | 其中非桃園市警局處理 |
|---|---|---|
| A1 | 1,036 筆 | 83 筆（國道 79、航警 4） |
| A2 | 251,845 筆 | 6,223 筆（國道 5,684、航警 408、保二 129、鐵警 2） |

反向不會有問題：桃園市警局處理的案件，發生地點都在桃園市。
